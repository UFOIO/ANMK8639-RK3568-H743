# RK3568 ↔ STM32H743 通信协议规范 V1.0

> 本文档供 STM32 固件团队参考，实现 USB CDC 串口通信协议
> RK3568 为上位机(主)，STM32H743 为下位机(从)

---

## 一、物理层

| 参数 | 值 |
|------|-----|
| 接口 | USB CDC ACM (虚拟串口) |
| 设备路径(RK3568侧) | /dev/ttyACM0 |
| 波特率 | **115200** |
| 数据位 | 8 |
| 停止位 | 1 |
| 校验位 | 无 |
| 流控 | 无 |

## 二、帧结构

```
+--------+--------+--------+----------+----------+--------+--------+
| 帧头   | 地址   | 命令   | 数据长度  |   数据    | CRC16  | 帧尾   |
| 2 Byte | 1 Byte | 1 Byte | 2 Byte   |  N Byte  | 2 Byte | 2 Byte |
| 0xAA55 | 0x01   | CMD    | Len(LE)  | Payload  | MODBUS | 0x55AA |
+--------+--------+--------+----------+----------+--------+--------+
```

| 字段 | 偏移 | 长度 | 说明 |
|------|------|------|------|
| 帧头 | 0 | 2 | 固定 0xAA 0x55，用于帧同步 |
| 地址 | 2 | 1 | 固定 0x01（STM32H743 本机地址） |
| 命令 | 3 | 1 | 指令类型，见第三、四节 |
| 数据长度 | 4 | 2 | 数据区字节数，小端序(LE)，最大 512 |
| 数据 | 6 | N | 变长载荷，格式取决于命令 |
| CRC16 | 6+N | 2 | MODBUS-CRC16，计算范围：地址+命令+长度+数据 |
| 帧尾 | 8+N | 2 | 固定 0x55 0xAA，用于帧边界确认 |

**最小帧长：9 字节**（数据长度=0）  
**最大帧长：521 字节**（数据长度=512）

### 帧同步状态机

```
1. HUNT_HEAD1: 逐字节读，直到 0xAA
2. HUNT_HEAD2: 读下一字节，期望 0x55，否则回到步骤1
3. READ_ADDR:  读地址
4. READ_CMD:   读命令
5. READ_LEN:   读2字节数据长度(LE)
6. READ_DATA:  读N字节数据
7. READ_CRC:   读2字节CRC，与计算值比较 -> 不匹配则丢弃，回到步骤1
8. READ_TAIL:  读2字节，期望 0x55 0xAA -> 确认帧完整
9. 回到步骤1
```

## 三、下行指令（RK3568 -> STM32）

### 指令总表

| 命令码 | 指令名 | 数据区 | 说明 | 需要ACK |
|--------|--------|--------|------|---------|
| 0x01 | OPEN_DOOR | 无(长度=0) | 打开机库舱门 | YES |
| 0x02 | CLOSE_DOOR | 无(长度=0) | 关闭机库舱门 | YES |
| 0x03 | LOCK | 无(长度=0) | 电磁锁上锁 | YES |
| 0x04 | UNLOCK | 无(长度=0) | 电磁锁解锁 | YES |
| 0x10 | GET_STATUS | 无(长度=0) | 查询当前状态 | YES |
| 0x11 | GET_SENSORS | 无(长度=0) | 查询传感器数据 | YES |
| 0x12 | HEARTBEAT | 无(长度=0) | 心跳检测(可选) | YES |
| 0x20 | SOFT_RESET | 无(长度=0) | 软复位(重启MCU) | YES |
| 0x30 | ENTER_IAP | 无(长度=0) | 进入固件升级模式 | YES |
| 0x31 | IAP_DATA | 见下方 | 固件数据块传输 | YES |
| 0x32 | IAP_FINISH | 4B: MD5校验前缀 | 升级完成+校验 | YES |

### IAP_DATA 数据区格式

```
+--------------+----------+
| 块序号       | 数据      |
| 4 Byte LE    | N Byte   |
+--------------+----------+
块序号: 从0开始递增
数据: 每块1024字节(最后一块可能不足)
```

### 示例帧(十六进制)

```
开舱门 (无数据, CRC假设为 0xC2F2):
  AA 55 01 01 00 00 F2 C2 55 AA

查询状态:
  AA 55 01 10 00 00 XX XX 55 AA

IAP数据块 (块0, 携带1024字节数据, 长度=1028=0x0404):
  AA 55 01 31 04 04 00 00 00 00 [1024字节] XX XX 55 AA
```

## 四、上行数据（STM32 -> RK3568）

| 命令码 | 上报名 | 触发方式 |
|--------|--------|---------|
| 0x80 | STATUS_REPORT | 周期上报(500ms) |
| 0x81 | SENSOR_DATA | 周期上报(1s) |
| 0x82 | ALARM | 事件触发(状态变化即时上报) |
| 0x83 | CMD_ACK | 收到指令后立即回复 |

### 4.1 STATUS_REPORT (0x80) - 8字节

```
+----------+----------+--------------+--------------+--------------+
| 舱门状态 | 锁状态   | 告警标志      | 温度          | 湿度          |
| 1 Byte   | 1 Byte   | 2 Byte LE    | 2 Byte LE    | 2 Byte LE    |
+----------+----------+--------------+--------------+--------------+

舱门状态: 0x00=关闭  0x01=打开  0x02=运动中  0xFF=未知
锁状态:   0x00=解锁  0x01=上锁  0xFF=未知
告警标志: 位掩码, 含义同 ALARM (见4.3节)
温度:     int16, 单位 0.1度 (例: 285 = 28.5度C)
湿度:     uint16, 单位 0.1%  (例: 650 = 65.0%)
```

### 4.2 SENSOR_DATA (0x81) - 8字节 (可扩展)

```
+------------------+------------------+--------------+
| 电源电压         | 电流             | 预留          |
| 2 Byte LE (mV)   | 2 Byte LE (mA)   | 4 Byte       |
+------------------+------------------+--------------+
```

### 4.3 ALARM (0x82) - 4字节位掩码

```
Bit 0: 电机过流/堵转
Bit 1: 限位开关异常
Bit 2: 温度过高 (>60度C)
Bit 3: 电源异常
Bit 4: 通信看门狗超时
Bit 5-31: 预留
```

> 上报策略：状态变化时立即上报；持续存在时每5秒重报一次

### 4.4 CMD_ACK (0x83) - 3字节

```
+--------------+--------------+--------------+
| 原指令码     | 执行结果      | 错误码       |
| 1 Byte       | 1 Byte       | 1 Byte       |
+--------------+--------------+--------------+

执行结果:
  0x00: 成功
  0x01: 失败
  0x02: 执行超时
  0xFF: 未知指令

错误码(仅失败时有效):
  0x01: 电机驱动故障
  0x02: 限位开关超时
  0x03: 指令冲突(当前忙)
  0x04: 安全互锁阻止
  0xFF: 未知错误
```
