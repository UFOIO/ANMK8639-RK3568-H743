### 1.1 模块：core/event_bus.py —— 内部事件总线

```
职责：模块间解耦通信，发布-订阅模式

事件类型枚举：
  DRONE_HEARTBEAT      # 无人机心跳更新
  DRONE_POSITION       # 无人机位置更新
  DRONE_BATTERY_LOW    # 无人机低电量告警
  DRONE_DISCONNECTED   # 无人机失联
  DRONE_RTL            # 无人机进入返航模式
  HANGAR_STATUS        # 机库状态更新（来自STM32）
  HANGAR_ALARM         # 机库告警（来自STM32）
  STM32_DISCONNECTED   # STM32通信中断
  MQTT_COMMAND         # 收到地面站MQTT指令
  DECISION_ACTION      # 决策引擎产出动作
  SYSTEM_HEALTH        # 系统健康状态

API:
  subscribe(event_type, callback)    # 订阅事件
  publish(event_type, data)          # 发布事件
  unsubscribe(event_type, callback)  # 取消订阅
```

**实现方式：** 基于 Python `queue.Queue` + 单线程轮询（无需 asyncio 重型框架，先用最简单的）

**预估工时：0.5 人天**

### 1.3 模块：modules/mqtt_client.py —— MQTT 通信

```
依赖: paho-mqtt >= 1.6

配置项 (config.yaml):
  mqtt:
    broker: "xxx.xxx.xxx.xxx"
    port: 1883
    client_id: "hangar_001"
    username: "admin"
    password: "xxx"

Topic 设计:
  上行 (RK3568 → 地面站):
    hangar/status          # 机库全量状态 (定时上报，5s周期)
    hangar/drone/telemetry # 无人机遥测摘要 (定时上报，1s周期)
    hangar/alarm           # 告警事件 (即时上报)
    hangar/event           # 业务事件 (舱门开关/起降等)
    hangar/upgrade/status  # 升级进度上报
  下行 (地面站 → RK3568):
    hangar/command         # 调度指令
    hangar/config/set      # 远程参数配置
    hangar/upgrade/start   # 发起STM32固件升级

消息信封格式 (统一):
  {
    "msg_id": "uuid",
    "ts": 1719494400.123,
    "type": "telemetry|alarm|event|command|ack",
    "payload": { ... }
  }

类: MQTTClient
  __init__(config, event_bus)
  connect()
  disconnect()
  publish(topic, msg_type, payload)
  subscribe(topic)
  _on_connect(client, userdata, flags, rc)
  _on_disconnect(client, userdata, rc)
  _on_message(client, userdata, msg)    # 下行指令解析 → event_bus.publish('MQTT_COMMAND')
  _on_heartbeat_timer()                 # 定时器，周期上报状态
  _reconnect_loop()                     # 断线重连（指数退避）
```

### 1.4 模块：modules/mavlink_client.py —— MAVLink 无人机通信

```
依赖: pymavlink >= 2.4

配置项 (config.yaml):
  mavlink:
    host: "xxx.xxx.xxx.xxx"         # 4G图数一体模块IP
    port: 5760                       # TCP端口 (常见: 5760 或 14550)
    reconnect_interval: 3            # 重连间隔(秒)
    heartbeat_timeout: 5             # 心跳超时(秒), 超时视为失联
    system_id: 255                   # 本机system_id (GCS默认255)
    component_id: 1                  # 本机component_id

类: MAVLinkClient
  __init__(config, event_bus, app_state)
  connect()           # 建立TCP连接，发送心跳
  disconnect()
  _recv_loop()        # 读TCP → parse → dispatch
  _parse_frame(buf)   # MAVLink v2 帧解析
  _dispatch(msg)      # 根据 msg_id 路由到对应handler
  _send_heartbeat()   # 定时向飞控发送心跳 (MAV_TYPE_GCS)

  # 消息处理器 (每个关键消息一个handler):
  _handle_heartbeat(msg)         # 更新: connected, flight_mode, armed
  _handle_global_position(msg)   # 更新: lat, lon, alt, heading
  _handle_attitude(msg)          # 更新: 姿态角
  _handle_battery_status(msg)    # 更新: 电压/剩余电量 → 低电量判定
  _handle_sys_status(msg)        # 更新: 传感器健康
  _handle_vfr_hud(msg)           # 更新: 速度/高度
  _handle_statustext(msg)        # 记录飞控文本消息(日志)

  处理完成后 → event_bus.publish('DRONE_XXX', data)

状态机 (内部):
  DISCONNECTED → 连接TCP成功 → CONNECTED
  CONNECTED → 收到HEARTBEAT → ACTIVE
  ACTIVE → heartbeat_timeout秒无心跳 → DISCONNECTED
  ACTIVE → TCP断开 → DISCONNECTED
```

### 1.5 模块：modules/stm32_comm.py —— USB 串口通信

```
依赖: pyserial >= 3.5

配置项 (config.yaml):
  stm32:
    port: "/dev/ttyACM0"          # USB CDC 设备路径
    baudrate: 115200
    timeout: 0.1                    # 串口读超时(秒)
    reconnect_interval: 3           # 串口断开重连间隔
    cmd_retry: 3                    # 指令发送重试次数
    cmd_timeout: 0.5                # 等待ACK超时(秒)

类: STM32Comm
  __init__(config, event_bus, app_state)
  open()
  close()
  send_command(cmd_id, payload) → bool   # 发送指令，等待ACK
  _recv_loop()                            # 读串口 → 帧解析 → 更新app_state → 发布事件
  _parse_frame(buf)                       # 帧同步 → CRC校验 → 提取数据
  _send_frame(addr, cmd, data)            # 帧封装 → CRC → 发送
  _handle_data_frame(cmd, payload)        # 处理上行数据（状态/告警/应答）
  _cmd_queue_worker()                     # 指令队列消费者

指令定义 (下行 RK → STM32):
  0x01 OPEN_DOOR       # 开舱门
  0x02 CLOSE_DOOR      # 关舱门
  0x03 LOCK            # 上锁
  0x04 UNLOCK          # 解锁
  0x10 GET_STATUS      # 查询状态
  0x11 GET_SENSORS     # 查询传感器数据
  0x20 RESET           # 软复位
  0x30 ENTER_IAP       # 进入升级模式
  0x31 IAP_DATA         # 升级数据块
  0x32 IAP_FINISH       # 升级完成确认

数据上报定义 (上行 STM32 → RK):
  0x80 STATUS_REPORT   # 状态主动上报(周期性)
  0x81 SENSOR_DATA     # 传感器数据
  0x82 ALARM           # 告警上报
  0x83 CMD_ACK         # 指令应答

帧结构 (见 protocol/stm32_proto.py):
  帧头(2B: 0xAA55) + 地址(1B) + 命令(1B) + 数据长度(2B LE) + 数据(NB) + CRC16(2B) + 帧尾(2B: 0x55AA)
  总帧长 = 9 + N 字节
```

**预估工时：3 人天 (RK3568侧) | STM32侧另外估算**

```python
# 伪代码 — 展现启动流程

def main():
    # 1. 加载配置
    config = ConfigLoader('config.yaml')

    # 2. 初始化日志
    logger = setup_logger(config.log)

    # 3. 初始化核心组件
    event_bus = EventBus()
    app_state = AppState()
    watchdog = Watchdog(config, event_bus)

    # 4. 初始化功能模块
    mqtt = MQTTClient(config.mqtt, event_bus)
    mavlink = MAVLinkClient(config.mavlink, event_bus, app_state)
    stm32 = STM32Comm(config.stm32, event_bus, app_state)
    camera = CameraCapture(config.camera)
    decision = DecisionEngine(config.decision, event_bus, app_state)

    # 5. 启动功能模块
    for mod in [mqtt, mavlink, stm32, camera, decision]:
        mod.start()

    # 6. 启动看门狗
    watchdog.start()

    # 7. 进入主循环 (信号等待)
    signal.pause()   # 等待 SIGTERM/SIGINT

    # 8. 优雅关闭
    for mod in reversed([mqtt, mavlink, stm32, camera, decision]):
        mod.stop()
    logger.info('System stopped')
```

### 2.2 STM32 协议帧定义

```
帧结构 (参考 protocol/stm32_proto.py):

┌────────┬────────┬────────┬──────────┬──────────┬────────┬────────┐
│ 帧头   │ 地址   │ 命令   │ 数据长度  │   数据    │ CRC16  │ 帧尾   │
│ 2 Byte │ 1 Byte │ 1 Byte │ 2 Byte   │  N Byte  │ 2 Byte │ 2 Byte │
│ 0xAA55 │ 0x01   │ CMD    │ Len(LE)  │ Payload  │MODBUS  │ 0x55AA │
└────────┴────────┴────────┴──────────┴──────────┴────────┴────────┘

地址: 0x01 = STM32H743 本机地址
CRC16: MODBUS-CRC16, 计算范围: 地址+命令+长度+数据

示例帧 (开舱门指令):
  AA5501 01 0200  C2F2 55AA
  帧头    地址 命令 长度=2 LE 数据=空 CRC  帧尾

示例帧 (状态上报, 数据=4字节):
  AA5501 80 0400 01000000  XXXX 55AA
  帧头    地址 命令 长度=4 LE 数据=舱门关闭 CRC  帧尾
```

  [Install]
