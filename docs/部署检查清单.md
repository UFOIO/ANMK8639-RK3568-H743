## 第七步: 重启持久化测试

```bash
# 物理断电 (拔电源)
# 等 90 秒
# 插电源
# SSH 进去
# 跑 8 步验证
```

8 步验证命令:
```bash
echo "=== 1. eth0 ==="; ip addr show eth0 | grep "inet "
echo "=== 2. WiFi ==="; nmcli device status | grep wlan0; ip addr show wlan0 | grep "inet "
echo "=== 3. soft-block ==="; rfkill list | grep -A 1 phy0
echo "=== 4. ip_forward ==="; cat /proc/sys/net/ipv4/ip_forward
echo "=== 5. iptables ==="; sudo iptables -L FORWARD -n | grep -E "192.168.144|policy"
echo "=== 6. Tailscale ==="; sudo tailscale status | head -3
echo "=== 7. 云台通 ==="; ping -c 2 192.168.144.25
echo "=== 8. 公网通 ==="; ping -c 2 baidu.com
```

- [ ] 8 项全绿 (eth0 / WiFi / soft-block / ip_forward / iptables / Tailscale / 云台 / 公网)

## 常见问题

| 问题 | 解决 |
|---|---|
| WiFi 连不上 H4T_4G | `sudo rfkill unblock wifi && sudo nmcli radio wifi off && sudo nmcli radio wifi on` |
| Tailscale 显示 offline | `sudo systemctl restart tailscaled` |
| 云台 ping 不通 | 检查 4G 模块是否上电, WiFi 距离是否在范围内 |
| iptables 规则丢了 | `sudo netfilter-persistent save` 重新持久化 |
| submodule import error | `sudo rm -rf /opt/hangar/modules/__pycache__` 后重启 |
| 8080 端口被占 | `sudo lsof -i :8080` 看是哪个进程, 杀掉 |
