## 前置: sudo NOPASSWD 配置 (供 Web UI [应用配置] 按钮用)

dashboard.html 的 [应用配置] 按钮会调 `/api/apply/*` → 后端 `sudo -n bash deploy/setup_*.sh`,
必须给 kickpi 用户加 NOPASSWD 权限, 否则 Web UI 按钮会失败 (但手动 SSH 跑脚本正常).

SSH 进去执行 (推荐方法 1, 严格只允许跑 deploy/setup_*.sh):

```bash
sudo bash -c 'cat > /etc/sudoers.d/kickpi-hangar << EOF
kickpi ALL=(ALL) NOPASSWD: /bin/bash /home/kickpi/rk3568_app/deploy/setup_*.sh
EOF'
sudo chmod 440 /etc/sudoers.d/kickpi-hangar
```

**验证**: `sudo -n true && echo "OK"` (应输出 OK, 不要求输入密码)

> 💡 即使不配 NOPASSWD, dashboard.html 板块下方仍显示 "手动命令" 提示框,
> 用户可以一键复制 SSH 命令粘贴到终端执行 (不需要 NOPASSWD 也行).

```bash
echo "=== 6. Tailscale ==="; sudo tailscale status | head -3

echo "=== 8. 公网通 ==="; ping -c 2 baidu.com
```

## 常见问题

| 问题 | 解决 |
|---|---|
| WiFi 连不上 H4T_4G | `sudo rfkill unblock wifi && sudo nmcli radio wifi off && sudo nmcli radio wifi on` |
| Tailscale 显示 offline | `sudo systemctl restart tailscaled` |
| 云台 ping 不通 | 检查 4G 模块是否上电, WiFi 距离是否在范围内 |
| iptables 规则丢了 | `sudo netfilter-persistent save` 重新持久化 |
| submodule import error | `sudo rm -rf /opt/hangar/modules/__pycache__` 后重启 |
| 8080 端口被占 | `sudo lsof -i :8080` 看是哪个进程, 杀掉 |


## 第 8 步 (新): Web UI 一键应用网络/VPN/云台配置

`deploy/setup_*.sh` 脚本已改造为从 `/etc/hangar/local.yaml` 读取参数。
可通过 dashboard.html 直接点 **[应用配置]** 按钮触发, 无需 SSH。

### 8.1 上位机浏览器打开配置页

访问 `http://192.168.2.78:8080/config` (RK3568 内网) 或
`http://100.84.131.95:8080/config` (Tailscale 跨公网)

### 8.2 推荐配置顺序

1. **网络配置** 板块: 填 4G WiFi SSID/密码 → [保存] → [应用配置]
   - 内部跑 `setup_network.sh`: 重启 NetworkManager / 重连 WiFi / 改 iptables
   - 会断网 10-30 秒, 完成后自动恢复

2. **VPN / Tailscale** 板块: 填 Auth Key → [保存] → [应用配置]
   - 内部跑 `setup_tailscale.sh`: 重新加入网络 + 广播子网路由
   - 几秒后客户 PC 自动学到 192.168.144.0/24

3. **云台相机存储** 板块: 勾选启用 + 填 IP/Web Port → [保存] → [应用配置]
   - 内部跑 `setup_camera.sh`: 重写 `/etc/hangar/go2rtc.yaml`
   - go2rtc 暴露云台 RTSP (`rtsp://<rk3568>:8554/main.264`) 供跨公网访问

### 8.3 实时日志

每个 [应用配置] 按钮启动后台任务, dashboard 实时显示最后一行输出。
完成后点击旁边的 [查看日志] 弹窗显示完整 stdout/stderr。

### 8.4 应急: 直接 SSH 跑脚本

如果 Web UI 不可用 (例如断网后还没配通):

```bash

sudo bash /home/kickpi/rk3568_app/deploy/setup_tailscale.sh
sudo bash /home/kickpi/rk3568_app/deploy/setup_camera.sh
```
