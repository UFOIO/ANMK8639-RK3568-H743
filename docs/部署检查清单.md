# RK3568 部署检查清单

> 按顺序执行，每步打勾确认。

---

## 第一步：RK3568 环境确认（SSH执行）

```bash
uname -a                    # 期望: aarch64
python3 --version           # 期望: >= 3.8
pip3 --version              # 没有则: sudo apt install python3-pip -y
df -h /                     # 磁盘空间 >= 200MB
free -h                     # 内存 >= 512MB
ip addr show                # 记下IP
```

- [ ] 系统为 aarch64 Linux
- [ ] Python >= 3.8
- [ ] pip3 可用
- [ ] 磁盘 >= 200MB
- [ ] 内存 >= 512MB

---

## 第二步：安装 Python 依赖（SSH执行）

```bash
pip3 install pyserial paho-mqtt pymavlink pyyaml
python3 -c "import serial,paho.mqtt.client,pymavlink,yaml; print('OK')"
sudo apt update && sudo apt install ffmpeg -y
ffmpeg -version
```

- [ ] pyserial / paho-mqtt / pymavlink / pyyaml / ffmpeg 全部就绪

---

## 第三步：上传代码（PC执行）

```powershell
# 替换 <IP> 为 RK3568 实际 IP
scp -r rk3568_app root@<IP>:/home/root/
```

- [ ] 代码已上传到 RK3568 /home/root/rk3568_app

---

## 第四步：修改配置（SSH执行）

```bash
cd /home/root/rk3568_app
nano config.yaml
```

必须修改：mqtt.broker, mqtt.username, mqtt.password, mavlink.host, stm32.port

- [ ] config.yaml 参数已填入实际值

---

## 第五步：首次运行测试（SSH执行）

```bash
cd /home/root/rk3568_app
python3 main.py         # 前台运行
# Ctrl+C 停止
tail -f data/logs/app.log  # 看日志
```

预期日志应包含:
- Logger initialized
- MQTT started
- MAVLink started
- STM32Comm started
- All modules started. Entering main loop.

- [ ] 程序正常启动，无崩溃

---

## 第六步：各链路验证

### MQTT
- [ ] 日志出现 "MQTT connected"
- [ ] 地面站收到 hangar/status（每5秒）

### USB 串口
- [ ] `ls /dev/ttyACM*` 能看到设备
- [ ] 日志出现 "Serial opened" 和 STATUS_REPORT

### 摄像头
```bash
ffplay rtsp://10.6.3.57:554/user=admin&password=&channel=1&stream=0.sdp?
```
- [ ] RTSP 能拉流显示画面

### MAVLink
- [ ] 日志出现 "MAVLink TCP connected"
- [ ] 收到 HEARTBEAT 消息

---

## 第七步：设为开机自启

```bash
sudo cp /home/root/rk3568_app/deploy/hangar.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable hangar
sudo systemctl start hangar
sudo systemctl status hangar
```

- [ ] systemd 服务运行正常
- [ ] `sudo reboot` 后能自动启动

---

## 常见问题

| 问题 | 解决 |
|------|------|
| ModuleNotFoundError: xxx | pip3 install xxx |
| /dev/ttyACM0 not found | 检查USB线供电, dmesg | grep tty |
| MQTT connect failed | ping broker_ip, 检查端口/密码 |
| ffmpeg not found | sudo apt install ffmpeg -y |
